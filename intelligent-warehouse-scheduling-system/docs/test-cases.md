## 2. 用户操作手册

### 2.1 系统登录

1. 打开浏览器访问系统地址（默认：http://localhost:5173）
2. 系统自动加载数据并进入主界面

### 2.2 仓库视图操作

#### 2.2.1 基本导航

- **平移视图**：按住鼠标右键拖动画布
- **缩放视图**：使用鼠标滚轮
- **重置视图**：双击空白区域

#### 2.2.2 楼层切换

1. 点击顶部工具栏的楼层选择下拉框
2. 选择目标楼层
3. 系统自动加载该楼层的布局和数据

#### 2.2.3 货架编辑

1. 点击顶部"编辑模式"按钮进入编辑状态
2. 拖拽货架调整位置
3. 点击货架可编辑属性（名称、尺寸等）
4. 完成后点击"保存"按钮

#### 2.2.4 库位查询

1. 点击任意库位查看详情
2. 在右侧面板查看库位编码、状态、库存信息
3. 使用搜索框快速定位库位

### 2.3 波次管理操作

#### 2.3.1 创建波次

1. 点击左侧菜单进入"波次管理"页面
2. 点击"智能生成波次"按钮
3. 设置参数：
   - 最大订单数：建议10-20
   - 最大商品数：建议50-100
4. 点击"生成"按钮
5. 系统自动分析订单并生成波次建议

#### 2.3.2 执行波次

1. 在波次列表中选择待执行的波次
2. 点击"执行"按钮
3. 系统自动：
   - 分配机器人
   - 规划路径
   - 开始执行
4. 切换到仓库视图可实时监控执行进度

#### 2.3.3 波次监控

- **波次卡片**：显示订单数量、机器人数量、完成进度
- **执行详情**：点击波次查看任务列表和执行状态
- **取消波次**：点击"取消"可终止执行中的波次

### 2.4 库存管理操作

#### 2.4.1 库存查询

1. 进入"库存管理"页面
2. 使用搜索框输入商品名称或库位编码
3. 使用筛选条件按状态、分类过滤
4. 查看库存统计图表和分布

#### 2.4.2 库存预警

- 红色标记：库存低于安全阈值
- 黄色标记：库存接近安全阈值
- 点击预警项查看详情和处理建议

### 2.5 异常事件处理

#### 2.5.1 查看异常

1. 进入"异常事件"页面
2. 按严重程度筛选：
   - 红色：严重
   - 橙色：高
   - 黄色：中
   - 蓝色：低
3. 点击异常查看详细信息

#### 2.5.2 处理异常

1. 选择待处理的异常
2. 点击"处理"按钮
3. 填写处理人、处理方案
4. 点击"确认处理"
5. 系统记录处理日志

### 2.6 调度日志查看

1. 进入"调度日志"页面
2. 选择日志类型：
   - 系统日志
   - 任务日志
   - 机器人日志
   - 异常日志
3. 设置时间范围和级别
4. 导出日志报告（如需）

## 3. 常见问题解答

### Q1: 机器人不执行任务怎么办？

**排查步骤：**
1. 检查机器人状态是否为"空闲"
2. 确认机器人电量充足（≥20%）
3. 检查任务是否已分配给该机器人
4. 查看异常日志是否有报错

### Q2: 波次执行卡住了怎么办？

**处理方法：**
1. 检查是否有机器人故障
2. 查看是否有路径冲突或拥堵
3. 尝试取消波次后重新执行
4. 如持续故障，联系技术支持

### Q3: 页面加载缓慢怎么办？

**优化建议：**
1. 检查网络连接
2. 清除浏览器缓存
3. 减少同时显示的数据量
4. 使用Chrome或Edge浏览器

### Q4: 数据不同步怎么办？

**处理方法：**
1. 刷新页面重新加载
2. 检查WebSocket连接状态
3. 确认后端服务正常运行
4. 查看控制台是否有报错
